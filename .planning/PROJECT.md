# Веб-конфигуратор металлических шкафов-локеров «Промет»

## What This Is

Внутренний веб-инструмент для менеджеров и директоров филиалов ООО «НПО Промет». Позволяет быстро собрать нестандартную конфигурацию металлического шкафа-локера (серия, модель, габариты, замок, вентиляция, цвет), получить итоговую цену и скачать два документа: КП для клиента и бланк нестандартного заказа (НЗ) для завода.

## Core Value

Любой сотрудник за 3 минуты собирает конфигурацию и получает готовые документы — без Excel, без Word, без ошибок.

### Out of Scope

- **3D-превью** — высокая стоимость разработки, нет ROI на текущем этапе
- **Автоматическая отправка email** — пользователи отправляют вручную через Outlook; серверная отправка не нужна
- **Интеграция с 1С** — единственный бэкенд Firebase; 1С интеграция не предусмотрена
- **Публичный доступ** — только внутренние сотрудники Промет
- **Мобильный UX** — отображение корректное, UX-оптимизация под мобильные отложена
- **Мультиязычность** — только русский язык

## Context

**Проблема:** Менеджеры тратят 20–40 минут на заявку, считая стоимость в Excel и собирая КП в Word. Высокий риск ошибок в спецификации нестандартных заказов.

**Пользователи:** Менеджеры по продажам и директора филиалов ООО «НПО Промет» — внутренние сотрудники. Роли не разделяются, сценарий одинаков для всех.

**Пользовательский путь:** выбрал серию/модель → задал нестандартные параметры → проверил цену → скачал КП → скачал бланк НЗ → отправил вручную через Outlook.

**Текущее состояние кодовой базы:**
- Компоненты перенесены в `src/components/ComponentName/` структуру
- Все CSS-классы упрощены (без BEM-префиксов родителя)
- Данные — временные заглушки (SERIES_OPTIONS, MODEL_OPTIONS, LOCK_OPTIONS, COLORS в коде)
- Parameters и Configurator не связаны через props — данные не текут между ними
- Расчёт цены не реализован (захардкожен 14 200 ₽)

**Валидация продукта:** после MVP (Этапы 1+2) — показ менеджеру и фокус-группа с директорами филиалов. Результаты фокус-группы могут скорректировать Этапы 3+4.

**Цена:** базовая цена модели (из Firebase) + наценки за каждый нестандартный параметр. Стандартная толщина — 0.5 мм для всех моделей. Контакты менеджера в КП — из Firebase.

## Constraints

- **Tech Stack:** React 19 + Vite 8 + MobX (планируется) — менять стек нельзя
- **Backend:** только Firebase (Firestore + Firebase Auth) — без серверной части, без 1С
- **Один разработчик:** 1 frontend-разработчик, стейкхолдер — менеджер Промет
- **Данные:** База цветов и наценок ожидается от команды Промет (данные из Excel); разработка не блокирует UI
- **Браузеры:** Chrome, Firefox, Safari, Edge 110+ — без IE/старых браузеров
