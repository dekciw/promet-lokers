# Руководство по развёртыванию

**Последнее обновление:** 23 июня 2026  
**Время развёртывания:** ~15 минут  
**Сложность:** Низкая

---

## Обзор

Это руководство поможет вам развернуть конфигуратор металлических шкафов «Промет» на Firebase Hosting. Приложение использует Firebase Authentication для авторизации пользователей и Firestore для хранения данных каталога.

### Что вы получите

- ✅ Работающее веб-приложение на Firebase Hosting
- ✅ Настроенную базу данных Firestore
- ✅ Систему авторизации пользователей
- ✅ SSL-сертификат и кастомный домен (опционально)

---

## Предварительные требования

Перед началом убедитесь, что установлены:

- **Node.js 18+** ([скачать](https://nodejs.org/))
- **Git** ([скачать](https://git-scm.com/))
- **Firebase CLI** (инструкция ниже)
- **Доступ к проекту Firebase** (консоль Firebase)

### Проверка установки

```bash
# Проверить версию Node.js
node --version
# Должно быть: v18.0.0 или выше

# Проверить версию npm
npm --version
# Должно быть: 8.0.0 или выше

# Проверить версию Git
git --version
```

---

## Шаг 1: Установка Firebase CLI

Установите Firebase CLI глобально:

```bash
npm install -g firebase-tools
```

Проверьте установку:

```bash
firebase --version
# Должно вывести версию, например: 13.0.0
```

---

## Шаг 2: Авторизация в Firebase

Войдите в аккаунт Google, связанный с проектом Firebase:

```bash
firebase login
```

Откроется браузер для входа. После успешной авторизации вы увидите сообщение:

```
✔ Success! Logged in as your-email@example.com
```

**Проверка:**

```bash
firebase projects:list
```

Вы должны увидеть список доступных проектов Firebase.

---

## Шаг 3: Клонирование репозитория

Клонируйте проект на локальный компьютер:

```bash
git clone <URL-репозитория>
cd Promet
```

**Проверка:**

```bash
ls -la
# Должны увидеть файлы: package.json, vite.config.js, firebase.json, src/
```

---

## Шаг 4: Создание файла .env

Создайте файл `.env` в корневой папке проекта со следующим содержимым:

```env
VITE_FIREBASE_API_KEY=ваш_api_key
VITE_FIREBASE_AUTH_DOMAIN=ваш_проект.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=ваш_проект_id
VITE_FIREBASE_STORAGE_BUCKET=ваш_проект.appspot.com
VITE_FIREBASE_MESSAGING_SENDER_ID=ваш_sender_id
VITE_FIREBASE_APP_ID=ваш_app_id
```

### Где взять значения

1. Откройте [Firebase Console](https://console.firebase.google.com/)
2. Выберите ваш проект
3. Перейдите в **Project Settings** (шестерёнка)
4. Прокрутите до раздела **Your apps** → **Web app**
5. Скопируйте значения из `firebaseConfig`

**⚠️ ВАЖНО:** Файл `.env` содержит конфиденциальные данные. Никогда не коммитьте его в Git!

## Шаг 5: Установка зависимостей

Установите все необходимые npm-пакеты:

```bash
npm install
```

Это займёт 2-3 минуты. После завершения появится сообщение:

```
added 300 packages, and audited 301 packages in 2m
```

**Проверка:**

```bash
ls -la node_modules/
# Должна появиться папка node_modules с зависимостями
```

---

## Шаг 6: Тестовый запуск локально

Перед развёртыванием убедитесь, что приложение работает локально:

```bash
npm run dev
```

Откройте браузер и перейдите по адресу:

```
http://localhost:5173
```

Вы должны увидеть страницу конфигуратора. Попробуйте:

- ✅ Войти в систему (если есть тестовый пользователь)
- ✅ Выбрать модель шкафа
- ✅ Изменить параметры

**Остановка dev-сервера:** Нажмите `Ctrl+C` в терминале.

---

## Шаг 7: Сборка проекта

Соберите production-версию приложения:

```bash
npm run build
```

После успешной сборки появится папка `dist/`:

```bash
ls -la dist/
# Должны увидеть: index.html, assets/, favicon.svg
```

**Проверка сборки:**

```bash
npm run preview
```

Откройте http://localhost:4173 и убедитесь, что приложение работает.

---

## Шаг 8: Проверка линтера и тестов

Перед деплоем запустите проверки качества кода:

```bash
# Проверка линтера
npm run lint

# Запуск тестов
npm test
```

Все проверки должны завершиться успешно:

```
✓ No linting errors found
✓ All tests passed (10 tests)
```

Если есть ошибки — исправьте их перед деплоем.

---

## Шаг 9: Инициализация Firebase проекта

Привяжите локальный проект к Firebase:

```bash
firebase use <ваш-project-id>
```

**Пример:**

```bash
firebase use promet-configurator
```

**Проверка:**

```bash
firebase projects:list
# Активный проект будет отмечен (current)
```

---

## Шаг 10: Развёртывание на Firebase Hosting

Разверните приложение на хостинг:

```bash
firebase deploy
```

Процесс займёт 1-2 минуты. После завершения вы увидите:

```
✔ Deploy complete!

Project Console: https://console.firebase.google.com/project/<project-id>/overview
Hosting URL: https://<project-id>.web.app
```

**Откройте URL в браузере и убедитесь, что приложение работает!**

---

## Шаг 11: Настройка кастомного домена (опционально)

Если нужно подключить собственный домен:

1. Откройте [Firebase Console](https://console.firebase.google.com/)
2. Перейдите в **Hosting** → **Add custom domain**
3. Введите ваш домен (например, `configurator.promet.com`)
4. Следуйте инструкциям для настройки DNS-записей
5. Дождитесь верификации (может занять до 24 часов)

После деплоя проверьте:

- ✅ Приложение открывается по URL
- ✅ Авторизация работает (можно войти/выйти)


## Откат к предыдущей версии

Если новая версия содержит ошибки:

```bash

firebase hosting:releases:list

firebase hosting:rollback
```

## Troubleshooting

### Проблема: `npm install` выдаёт ошибки

**Причина:** Несовместимая версия Node.js

**Решение:**

```bash
# Обновите Node.js до версии 18+
node --version
```

---

### Проблема: `firebase deploy` не работает

**Симптом:**

```
Error: HTTP Error: 403, Permission denied
```

**Решение:**

```bash
# Переавторизуйтесь
firebase logout
firebase login

# Проверьте активный проект
firebase use <project-id>
```

---

### Проблема: Приложение не загружается после деплоя

**Причина:** Неправильные переменные окружения

**Решение:**

1. Проверьте файл `.env`
2. Убедитесь, что все переменные начинаются с `VITE_`
3. Пересоберите проект:

```bash
npm run build
firebase deploy
```

---

### Проблема: База данных Firestore пустая

**Причина:** Данные каталога не загружены

**Решение:**

1. Войдите как администратор
2. Перейдите в админ-панель
3. Загрузите каталог через интерфейс управления
