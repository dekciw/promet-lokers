# Документация проекта

## Структура документации

**Назначение:** Пошаговая инструкция по развёртыванию приложения на Firebase Hosting

**Что внутри:**

- Создание файла `.env`
- Локальный запуск и тестирование
- Деплой на хостинг
- Troubleshooting

**Когда читать:** При первом развёртывании или переносе на новый сервер

---

- Авторизация в системе

- Генерация КП и НЗ
- История заказов
- Админ-панель (для администраторов)

**Когда читать:** Перед началом работы с приложением

---

**Когда читать:** При доработке функционала или отладке

## Быстрый старт

### Для заказчика (первый запуск)

1. **Развёртывание:**
   - Прочитайте [DEPLOYMENT.md](./DEPLOYMENT.md)
   - Выполните все шаги по порядку
   - Убедитесь, что приложение работает

2. **Начало работы:**
   - Прочитайте [USER_GUIDE.md](./USER_GUIDE.md)
   - Создайте первых пользователей
   - Загрузите каталог моделей

3. **Администрирование:**
   - Прочитайте [MAINTENANCE.md](./MAINTENANCE.md)
   - Настройте резервное копирование
   - Изучите раздел мониторинга

---

### Для разработчиков (доработка)

1. **Изучите архитектуру:**
   - Прочитайте [TECHNICAL_SPEC.md](./TECHNICAL_SPEC.md)
   - Ознакомьтесь со структурой проекта
   - Изучите Firebase структуру

2. **Локальный запуск:**
   - Следуйте инструкции из [DEPLOYMENT.md](./DEPLOYMENT.md)
   - Создайте `.env` файл
   - Запустите `npm install` и `npm run dev`

3. **Перед коммитом:**
   - Запустите `npm run lint`
   - Запустите `npm test`
   - Убедитесь, что `npm run build` проходит без ошибок
