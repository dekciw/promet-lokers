# Формула расчёта стоимости шкафов — Конфигуратор Промет

> Документ описывает **точную логику**, реализованную в `src/shared/utils/calcPrice.js`.  
> Все коэффициенты берутся из Google Sheets → Firebase. Если формула не совпадает с ожиданиями — нужно скорректировать таблицу и/или код.

---

## 1. Источники данных

### 1.1 Лист «Модели» (Google Sheets, gid=0)

Каждая строка — одна модель шкафа. Поля, используемые в расчёте:

| Столбец | Поле в коде | Описание |
|---------|-------------|----------|
| B | `article` | Артикул |
| C | `name` | Наименование |
| D | `id` | Уникальный ID модели |
| E | `seriesId` | Серия: `ml` или `ls` |
| J | `basePrice` | **Цена Min (₽)** — минимальная клиентская цена за стандартное исполнение |
| P | `cpBezNDS` | **ЦП без НДС (₽)** — заводская цена |
| N | `doorWeight` | Вес дверей (кг) |
| O | `bodyWeight` | Вес корпуса (кг) |
| Q | `doorCount` | Количество дверей (секций) — 1, 2, 4 и т.д. |
| G | `defaultSpecs.height` | Стандартная высота (мм) |
| H | `defaultSpecs.width` | Стандартная ширина (мм) |
| I | `defaultSpecs.depth` | Стандартная глубина (мм) |
| K | `defaultSpecs.bodyThickness` | Стандартная толщина корпуса (мм) |
| L | `defaultSpecs.doorThickness` | Стандартная толщина двери (мм) |

### 1.2 Лист «Price» (Google Sheets, gid=1504497578)

Содержит все коэффициенты доплат. Читается скриптом `scripts/sync-sheets.js` и записывается в Firebase в поле `priceRules`.

## 2. Параметры конфигурации (что выбирает менеджер)

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `quantity` | число | 10 | Количество шкафов |
| `discount` | % | 0 | Скидка для клиента (0–50%) |
| `bodyThickness` | '0.5' / '0.6' / '0.7' | из модели | Толщина металла корпуса (мм) |
| `doorThickness` | '0.5' / '0.6' / '0.7' | из модели | Толщина металла двери (мм) |

> **Ширина** — не считается изменением для целей расчёта цены (нет доплаты).

---

## 3. Подсчёт количества «исполнений»

**Исполнение** = любое отклонение от стандарта модели. Каждая позиция считается как 1 исполнение:

| Изменение | Считается как |
|-----------|--------------|
| Толщина корпуса | ┐ |
| Толщина двери   | ┘ вместе — 1 исполнение (даже если изменены оба) |
| Нестандартная глубина | 1 исполнение |
| Нестандартная высота | 1 исполнение |
| Замок (не key_basic) | 1 исполнение |
| Вентиляция (любой тип) | 1 исполнение |
| Нестандартный цвет двери | 1 исполнение |
| Нестандартный цвет корпуса | 1 исполнение |

**Максимум 2 исполнения** → цена считается автоматически.  
**3 и более исполнений** → выводится «По согласованию с производством» (расчёт вручную).

---

## 4. Расчёт итоговой наценки (totalRate)

Каждое изменение добавляет процент к базовой цене. `totalRate` — сумма всех процентов (в виде дробей: 10% = 0.10).

```
Итоговая наценка = Σ (доплата за каждое изменение)
```

Все проценты берутся из `priceRules` в Firebase.

### 4.1 Доплата за толщину металла

**Минимальное количество:** 100 шт. При меньшем количестве → «По согласованию».

Базовые ставки (от 100 шт.):

| Толщина | Ставка |
|---------|--------|
| 0.5 мм | 0% (стандарт, базовая цена) |
| 0.6 мм | 10% |
| 0.7 мм | 25% |

> ⚠️ **Пример из таблицы:** 0.5 мм → 10%, 0.6 мм → 25%, 0.7 мм → 85%.  
> Нужно уточнить у экономистов — 0.5 мм в таблице имеет ставку 10%, а не 0%.  
> **Текущий код:** любая толщина, отличная от стандарта модели, применяет ставку из таблицы.

**Расчёт с учётом веса (пропорциональный):**

- Если изменена только дверь:  
  `доплата = ставка_двери × (вес_двери / общий_вес)`

- Если изменён только корпус:  
  `доплата = ставка_корпуса × (вес_корпуса / общий_вес)`

- Если оба изменены **на одинаковую толщину**:  
  `доплата = ставка (полная, без пропорции)`

- Если оба изменены **на разную толщину**:  
  `доплата = ставка_двери × (вес_двери / общий_вес) + ставка_корпуса × (вес_корпуса / общий_вес)`

## 5. Доплата за нестандартный замок (фиксированная, ₽)

Замок не входит в `totalRate`. Его доплата добавляется к базовой цене **в рублях** (не процент).

| Замок | Односекционный | Двухсекционный (за секцию) |
|-------|---------------|--------------------------|
| Ключевой (Базовый) | 0 ₽ | 0 ₽ |
| Замок D111X-20-01/C247/J9Z | 150 ₽ | 280 ₽ |
| Замок Практик EL Code | 170 ₽ | 330 ₽ |
| Замок Euro Locks A129 | 195 ₽ | 370 ₽ |
| Замок Практик EL Mifare | 120 ₽ | 200 ₽ |

**Формула доплаты за замок:**
```
если doorCount = 1:
    lockSurcharge = lock.single

если doorCount = 2, 4, 6...:
    lockSurcharge = lock.dual × (doorCount / 2)
```

> `lock.dual` — цена за **2-секционный** шкаф. Для 4-секционного умножается на 2, для 6-секционного на 3.

---

## 6. Итоговые формулы

### 6.1 Клиентская цена (Цена Min)

```
Цена клиента = round(basePrice × (1 + totalRate) + lockSurcharge) × (1 - discount / 100)
```

- `basePrice` — колонка J листа «Модели» (Цена Min)
- `totalRate` — сумма всех процентных доплат (раздел 4)
- `lockSurcharge` — фиксированная доплата за замок в рублях (раздел 5)
- `discount` — скидка в процентах, задаётся менеджером (0–50%)

### 6.2 Заводская цена (ЦП без НДС)

```
Цена заводская = round(cpBezNDS × (1 + totalRate) + lockSurcharge)
```

- `cpBezNDS` — колонка P листа «Модели»
- Скидка к заводской цене **не применяется**

### 6.3 Вес

Вес пересчитывается с учётом толщины металла:

```
Вес = round(doorWeight × K_door + bodyWeight × K_body, 2)
```

Коэффициенты:

| Толщина | Коэффициент |
|---------|-------------|
| 0.5 мм | 1.000 (стандарт) |
| 0.6 мм | 1.333 (+33.3%) |
| 0.7 мм | 1.556 (+55.6%) |

### 6.4 Срок изготовления

| Количество исполнений | Срок |
|----------------------|------|
| 0 (стандарт) | — |
| 1 | 7–14 дней |
| 2 | 14–21–30 дней |
| 3+ | По согласованию |

---

## 7. Когда цена не считается автоматически

Система выводит **«По согласованию с производством»** в следующих случаях:

1. **Более 2 исполнений** одновременно (любая комбинация из раздела 3)
2. **Глубина нестандартная** при количестве **менее 10 шт.**
3. **Высота нестандартная** при количестве **менее 100 шт.**
4. **Толщина нестандартная** при количестве **менее 100 шт.**
5. **Высота или глубина**, которых нет в таблице коэффициентов

## 8. Пример расчёта

**Исходные данные:**
- Модель: ML-186 (basePrice = 12 000 ₽, cpBezNDS = 8 000 ₽)
- doorWeight = 15 кг, bodyWeight = 35 кг (итого 50 кг)
- Стандартная глубина: 400 мм, стандартная высота: 1600 мм
- Серия: ML

**Конфигурация:**
- Количество: 50 шт.
- Глубина: 450 мм (нестандарт → 1 исполнение)
- Замок: Практик EL Code
- Скидка: 5%

**Расчёт:**

```
1. Количество исполнений: 1 (глубина) + 1 (замок) = 2 → считаем

2. totalRate = доплата_глубина(ML, 450мм, 50шт)
             = 39% = 0.39

3. lockSurcharge (doorCount = 2, dual = 330 ₽):
   = 330 × (2/2) = 330 ₽

4. Цена клиента:
   = round(12 000 × 1.39 + 330) × (1 - 0.05)
   = round(16 680 + 330) × 0.95
   = round(17 010) × 0.95
   = 17 010 × 0.95
   = 16 160 ₽

5. Цена заводская:
   = round(8 000 × 1.39 + 330)
   = round(11 120 + 330)
   = 11 450 ₽

6. Вес (толщина стандартная 0.5 мм, K = 1.0):
   = 15 × 1.0 + 35 × 1.0 = 50 кг

7. Срок: 2 исполнения → 14–21–30 дней
```
